# Aurora-Developer-16

A clean, zero-dependency single-page web application and developer showcase built for **Aurora-Developer-16**, ready to upload to GitHub and publish via **GitHub Pages**.

## Features

- **Aurora Dark Theme:** Custom CSS variables and ambient gradient styling with responsive layout across desktop and mobile screens.
- **Scalable Vector Emblem:** Inline SVG mark matching the Aurora theme with crisp rendering at any DPI.
- **Interactive 16-Bit Value Inspector:** Convert any `0–65535` integer live into 4-digit hexadecimal, grouped 16-bit binary, and high/low byte pairs.
- **Zero Build Step:** Pure HTML, CSS, and vanilla JavaScript in a single `index.html` file.
